# ⚡ Image Processing Pipeline

A high-performance image processing pipeline focused on low latency, efficient memory usage, and scalable transformations.

---

## 🚀 Features

- 📦 Image Compression (size reduction with minimal quality loss)
- 🔄 Format Conversion (PNG ↔ JPG ↔ WEBP)
- 📏 Image Resizing
- ⚡ Optimized for speed and low latency
- 🧠 Memory-efficient processing

---

## 🧩 Architecture Overview

The pipeline is designed with performance and scalability in mind:

- Stream-based image processing (avoids full memory load)
- Controlled concurrency (prevents CPU/memory spikes)
- Modular transformation steps (compression, conversion, resize)
